# Sprout — Budget Buddy

A simple monthly budget planner for tracking income and expenses. Add transactions, organize them by category, and see your monthly balance at a glance. Your data is saved locally in your browser.

## Features

- Track income and expenses
- Add a description, amount, type, and category to each transaction
- View monthly income, spending, and balance
- Filter transactions by month
- Delete transactions
- Save data on your device using browser storage
- English and Amharic interface text

## Built with

- HTML
- CSS
- JavaScript

## Run locally

Download or clone this repository, then open the HTML file in your web browser.
